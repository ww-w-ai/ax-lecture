토큰 비용 절약하기 실전 체크리스트

1
output 길이를 짧게
상위 모델일수록 답변이 장황(output이 가장 비쌈) → “정확하고 짧게” 지시.
기존 콘텐츠 재가공은 LLM에 맡기지 말고 스크립트로 가공(토큰 0).
2
context 크기 모니터링·제어
윈도우가 커지면 아무리 캐시돼도 비용이 급증(제곱)
→ 주기적으로 크기 확인, 의도적으로 끊기
3
cache가 깨지지 않게 관리
콘텍스트가 큰데 1시간이 지나면 가급적 새 세션으로 (다시 캐싱하면 = 제곱 비용).
4
compact보다 새 세션 + 트랜스크립트로 복구
compact은 유실·노이즈 → 새 세션에서 트랜스크립트(.jsonl 기록)로 핵심만 복원.
