bkit 시작하기 — Quick Start

설치 → 첫 실행(단일 기능) → 여러 기능 릴리스, 명령 몇 줄로.
zsh — bkit quick start
# 1. 설치 (한 번만)
$ claude plugin install bkit # 2. 병렬 팀 실행 활성화 (선택 · 권장)
$ export CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 # 3. 첫 실행 — 단일 기능
$ /pdca pm my-feature   # 원하는 걸 설명 → 나머지는 bkit이 # 4. 여러 기능 릴리스가 준비되면
$ /sprint master-plan my-release --name "Q2 Launch" --features auth, billing, reports
  # (플랜을 승인)
$ /sprint start my-release-s1
