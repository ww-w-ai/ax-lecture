### P52 [🔧 실습] — Sprint 기획·설계까지 직접 (빌드 전까지)

> 출처: bkit `scenarios/scenario-sprint.md` + 유저 매뉴얼. **기획안·설계 작성까지만** — 실제 빌드(do)는 시간·한도 때문에 현장에선 생략(자습 시 이어서).

- **목표**: 한 명령으로 여러 기능의 **PRD → master-plan → 설계 문서**가 자동 생성되는 걸 직접 확인. (P40·P43의 실전)
- **따라하기**:
  1. `/sprint init my-app --features auth,profile,dashboard --trust L1`
  2. `/sprint start my-app` → **PRD + Plan 자동 작성 후 멈춤**(Trust **L1 = plan까지**).
  3. `/sprint phase my-app --to design` → **설계 문서까지** 생성. **여기서 STOP**(do/빌드는 안 함).
- **관찰 포인트 3개**: ① PRD에 문제·JTBD·페르소나·**성공지표**·Pre-mortem이 채워지나 ② master-plan이 "무엇을 먼저·무엇을 동시에"를 정리했나 ③ 각 기능의 design 문서가 생겼나.
- 비주얼: 터미널 `/sprint init … --trust L1` 입력 → 생성된 `prd.md · master-plan.md · *.design.md` 파일 트리 클로즈업.
