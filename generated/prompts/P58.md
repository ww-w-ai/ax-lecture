## [강연-슬라이드-구성안.md] 해당 페이지

### P58 [소개] — tene ②: 코드 한 줄 안 읽고 '지도'로 이해

> 비주얼 = 코드맵·인터페이스·API·데이터 실화면(스크린샷 002·003·004·005).

- **CodeMap(코드맵)** — 화면→기능→데이터 흐름을 마인드맵처럼 펼침. 점 하나(예: '주문 화면') 누르면 연결된 길이 빛난다 → "이게 다 어떻게 엮였나" 감이 잡힌다.
- **Interface(인터페이스)** — 어떤 화면들이 있고 어떻게 넘어가는지 트리로. 화면→기능→데이터 경로를 양방향 추적. *기획서·IA를 코드에서 자동 추출한 셈.*
- **API** — '개발자만 알던 API'를 쉬운 말로: "이 기능은 무엇을 입력받아 어느 데이터를 읽고/쓰나". **신뢰도까지 표기** → AI의 '그럴듯한 거짓말' 차단.
- **Data(데이터)** — 데이터 창고 지도(ERD): 표·관계를 그림으로 + 실제 저장값 안전 미리보기. "내 고객 데이터가 진짜 어디에 어떻게?"를 눈으로 확인.

### P58 tene ② 지도들 — [실화면 입력(스크린샷)] · 2×2 그리드
- **입력 = 코드맵(002)·인터페이스(003)·API(004)·데이터(005) 스크린샷 4장**. title 텍스트 레이어 "코드 한 줄 안 읽고 '지도'로 이해". 4장을 **2×2 그리드 카드**로 배치, 각 카드 상단 라벨 + 한 줄 설명:
  - **CodeMap**: 화면→기능→데이터 흐름 마인드맵 (점 누르면 길이 빛남)
  - **Interface**: 화면 트리 + 양방향 경로 추적 (기획서·IA 자동 추출)
  - **API**: '개발자 용어' 쉬운 번역 + **신뢰도 표기**(AI 거짓말 차단)
  - **Data**: ERD + 실제 저장값 안전 미리보기
