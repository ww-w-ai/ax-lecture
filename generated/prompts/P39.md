### P39 [신규·도식] — Sprint 개념 ④: Sprint 단계 × Trust L0~L4 (무인 범위 다이얼, SPRINT_AUTORUN_SCOPE)

> 출처: bkit `/control` (Trust L0~L4 · SPRINT_AUTORUN_SCOPE).

- **가로축 = Sprint 8단계**(한 줄): PRD → Plan → Design → Do → Iterate → QA → Report → Archived.
- **Trust 레벨 5개 = 무인 범위 다이얼**. 각 레벨은 축 위에서 **PRD부터 어디까지 자동으로 진행하는지**를 이어진 구간(range)으로 표시. 표시된 구간 = 자동 진행 / 나머지 = 사람 승인.
  - `L0 · Manual` — 자동 구간 없음(전부 사람 승인)
  - `L1 · Guided` — PRD까지
  - `L2 · Semi (기본)` — Design까지  ← **기본 안전값**
  - `L3 · Auto` — Report까지
  - `L4 · Full` — Archived까지(끝까지 무인)
- 레벨이 오를수록 구간이 오른쪽으로 길어지는 **계단형**(다이얼이 열린다).
- **자동 승격은 없다** — 성과로 벌어서 올린다. **품질 게이트는 레벨과 무관하게 항상 작동.**
- **한 줄**: L2가 기본 안전값 — 성과 쌓이면 L3·L4로. 품질 게이트는 레벨과 무관하게 항상 작동.
