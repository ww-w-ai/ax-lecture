  1. 기억: "너 내가 누군지 알아?" → 사전 프로필 로드해 신원·선호 정확 식별.
  2. 툴콜: "최근 GitHub 인기 프로젝트 검색" → 헤드리스 브라우저 자동 기동, 15회 툴콜(내비·스크롤·스크린샷)로 실시간 데이터 획득.
  3. **능동적 학습 제안(핵심)**: 실행 후 Hermes가 먼저 — "이건 매주 반복하는 작업이네요. 이 흐름을 Skill로 저장할까요? 지금 저장할까요?" → OpenClaw엔 없는 체험.
  4. Skill 품질: 자동 생성된 SKILL.md에 구체 URL·필터규칙·출력포맷 포함, 기대 이상.
  5. 피드백 반영: 3개 수정 요청 → Skill 파일 직접 재작성(검색범위 확대, 구어체 문안, 강의가치 분석 단계 추가).
  6. 폐루프: "GitHub 트렌드 분석" 5글자만 → 수정된 Skill 로드해 자동 실행, 문체·추가분석 반영됨.

  (번역: "Hermes의 개봉 체험은 네가 일주일 넘게 조련해둔 OpenClaw 같다.")
