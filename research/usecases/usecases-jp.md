# 일본어권 OpenClaw / Hermes Agent 실사용 사례 딥리서치

작성일: 2026-07-05 / 조사자: 강연·제품기획 딥리서치
목적: (1) 슬라이드용 임팩트 사례 (2) 수지(agent-sooji) 개발 목표로 삼을 "사람들이 진짜 원하고 감동한" 패턴

## 0. 제품 팩트 (실측 확인됨)

- **OpenClaw(オープンクロー)**: 오스트리아 개발자 Peter Steinberger 발. 2026년 초 폭발, GitHub 스타 2026.6 기준 37만8천+ (React 10년치를 2개월에 추월). 스마트폰에서 Telegram/WhatsApp/LINE/Discord/Slack으로 지시 → 클라우드/자택PC의 OpenClaw가 실제 조작. **철학 = "buddy AI"**: 하나의 지속 세션 유지, 사람처럼 기억이 리셋 안 됨(MEMORY.md + 데일리 저널). "heartbeat" 자율 주기 실행.
  - 보안: 2026.2 "ClawJacked" 취약점 — 무방비 공개된 약 4만 대 인스턴스가 악성 웹 열람만으로 탈취(API키 절도·임의 커맨드). "본번 환경 도입 비권장, 작은 태스크부터" 권고 반복.
- **Hermes Agent(ヘルメス)**: Nous Research 발, 2026.2 공개, MIT 라이선스. **철학 = "evolving AI"(育つAI, 자라는 AI)**: 세션은 태스크마다 fresh(context 청결, Claude Code `/clear`식), 대화이력은 SQLite에 검색용 저장. 핵심 = **Evolving Skills(자동 스킬 생성)** — 완료한 태스크에서 재사용 스킬을 자동 생성해 다음 유사 태스크에 호출. 3층 메모리 + 6층 보안 방어. SOUL.md + 100+ 프리셋 스킬. 운영비 월 $5~15. OpenRouter 사용량 기준 카테고리 최다 프레임워크.
- **주의(신뢰도)**: 일본어 웹에 explainer·마케팅·SEO 어필리에이트 글이 압도적으로 많음. 아래는 그중 **실제 1인칭 후기/데모**만 선별. 마케팅톤 "できる(가능)" 나열 글은 사례에서 제외하고 인사이트 참고용으로만.

### A. 업무 자동화 — 아침 브리핑·비서형 (가장 반복 등장, 감동 포인트)

- 작업: Discord에서 "영역=AI, 세부조건·제외요소 지정, 요약+소스 붙여 보고" 1줄 지시 → 매일 아침 자동. Google 캘린더 연동.

- 제품: Hermes / 출처: forest.watch.impress.co.jp/docs/serial/yaaiwatch/2113305.html / 신뢰도: 높음(전문 저널 핸즈온) / 유형: 업무자동화·능동적 비서

### D. "자라는 AI" 감동형 — 기억·자동 스킬생성 (수지 개발의 핵심 인사이트)

**D-1. Hiroaki(note) — OpenClaw→Hermes 갈아타고 "育つAI"에 감동**
- 작업: 같은 "VPS 로그 확인" 태스크 반복. 파일 정리 의뢰.
- 결과·인용: 초회는 상세 설명 필요했으나 「2回目以降は前回のやり方を記憶し、素早く本題に入れる」. 파일정리 의뢰 후 Hermes가 독자적으로 **"파일정리 스킬"을 자동생성** → 이후 유사 태스크에 재활용(자기개선 루프 실감). 1주 사용에 「高性能なAIツール → チームメンバー」로 인식 변화. OpenClaw는 스킬 수동생성이라 "쓰기만 해도 스킬이 늘어나는" 체험은 Hermes 고유.
- 제품: Hermes(vs OpenClaw) / 출처: note.com/major_elk2890/n/nfb846ad39082 / 신뢰도: 중~높음 / 유형: 자기개선·정서적 애착

**D-2. よへい(note) — "회사에 기억해주는 AI를 1명 맞이했다"**
- 작업: 정례회의 갈겨쓴 메모(불릿 5줄)를 데스크톱앱 채팅에 붙이고 "의사록으로. 결정사항·TODO·다음 이월로 나눠줘".
- 결과·인용: 수십 초에 결정사항 4건 분류, TODO 표(담당·기한: 佐藤 이번주중, 鈴木 6/20), 이월 1건. 모호한 "각자 다음까지"도 「担当：各自」「期限：次回定例まで」로 정확 입력. 「あ、これはもう十分使えるな」. 단 냉정하게 「通常のチャットAIでも同程度…想定通りな印象」(일반 챗AI도 이 정도는 함 — 상정 범위) — **단발 태스크에선 차별점 약함**을 정직 지적.
- 제품: Hermes / 출처: note.com/yoooheeei/n/n0e4570a7feba(전편) / 신뢰도: 높음(균형잡힌 1인칭) / 유형: 업무자동화·정직후기

## 3. 수지(agent-sooji) 개발 인사이트 3~5

1. **사람들이 진짜 감동한 것 = "자라는(記憶+자동 스킬생성)"이지 단발 태스크 성능이 아니다.** 단발 의사록/요약은 "일반 챗AI도 함(상정 내)"로 평가절하됨(D-2, F-1). 반면 "2회째부터 기억해 바로 본론", "쓰기만 해도 스킬이 늘어남"에서 "툴→팀 멤버"로 인식이 바뀜(D-1). → 수지는 반복 상호작용에서 개인화·스킬 축적이 **관측 가능하게 드러나는** 순간을 설계해야(F-1이 지적한 "단시간 체감 어려움"의 반대 = 조기 가치 증명 장치 필요).

2. **가장 넓게 꽂힌 킬러 유즈 = 능동적 아침 비서 + 능동 리마인드.** "그 예정 끝났나 / 마감 미루지 말고 즉시 착수하라 / 회의 2시간 전 논점 확인"처럼 **AI가 먼저 말 거는 능동성**(heartbeat/cron)이 반복 등장. 수동 Q&A가 아니라 선제적 개입이 감동 포인트. 수지의 캘린더·리마인더·track_metric을 이 "능동 브리핑" 서사로 묶을 것.

3. **진입장벽 붕괴가 열광의 뿌리.** "단 1줄로 자동태스크 등록", "채팅앱(LINE/Discord)에서 자연어로", "비엔지니어가 폐PC로". 반대로 Hermes는 Docker/Python/API키가 실제 장벽(E·A). 수지 = 이미 MCP/채팅 표면이라 이 장벽이 낮음 → 강점으로 전면화.

4. **병렬 서브에이전트 미디어 파이프라인이 크리에이터층을 끌어들임**(B-1: Qiita/note/Zenn 초안 + YouTube 쇼츠를 병렬로). 수지가 지향하는 "위임 실행" 서사와 정확히 일치 — 콘텐츠 제작 자동화를 데모 시나리오로.

5. **신뢰의 차별화 = 과장 안 하기 + 보안.** 일본 커뮤니티는 반증글(F-1)·보안 경고(ClawJacked, 사장 경고)를 정직히 공유하고 그게 더 신뢰받음. 수지 포지셔닝은 "자율이지만 안전 경계(비가역 게이트)·정직한 한계 고지"를 셀링포인트로 — 일본 특유의 정밀·신중 문화와 부합.
