# OpenClaw & Hermes Agent — 한국 커뮤니티 실사용 사례 딥리서치

> 조사일 2026-07-05. 컷오프(2026-01) 이후 사건이라 WebSearch/WebFetch 실측. 확인된 것/확인불가 구분.
> 소스 신뢰도 표기: [1인칭데모] = 실제 유저 후기·실행 / [기자·리뷰] = 매체 검증 / [해설] = 개념 정리(2차) / [확인불가]

## 제품 팩트 (확인됨)

- **OpenClaw (오픈클로)**: 2025-11 오스트리아 비엔나 Peter Steinberger 공개. 2026 초 GitHub ~18만 스타. 자체호스팅 게이트웨이 — Discord/Slack/Telegram/WhatsApp/iMessage 등 메신저를 AI 코딩 에이전트에 연결. **하트비트(Heartbeat)** = 명령 없이 주기적으로 깨어나 예약작업 수행. 핵심 엔진 = pi-mono(Mario Zechner, 도구 4개 read/write/edit/bash + SKILL.md 파일 스킬, 시스템프롬프트 <1000토큰). 보안사고: 공개 3주 만에 CVE-2026-25253(원클릭 RCE), 4만~13.5만 인스턴스 노출. 네이버·카카오 사내 사용 금지.
- **Hermes Agent (헤르메스)**: Nous Research(미국) 개발. 2026-02-25 오픈소스(MIT) 공개. 3개월 만에 ~14만 스타. OpenRouter 기준 일 2240억 토큰 처리(카테고리 1위 주장 — [확인불가] 수치). **차별점 = 영속 기억 + 스킬 자동생성**. 세션 종료 후에도 안 잊음. 매일 밤 작업 복기하며 진화. 백그라운드 리뷰 에이전트가 스킬로 남길지 검토 + 7일마다 Curator가 라이브러리 정리(중복 병합·미사용 솎기). OpenAI/Anthropic 호환 어떤 LLM도 연결.

## 유형별 실사용 사례

### A. 1인 개발자 운영 부담 경감 (DevOps 동료화) — 가장 감동 큰 패턴

**A1. 홈서버 24/7 에이전트 → "새벽 3시 장애, 아침에 PR이 올라와 있음"** [1인칭데모] 신뢰高
- 제품: OpenClaw(→ 자작 Solo Agent Hub로 발전)
- 작업: 장애감지→로그분석→PR생성→Slack승인→자동배포 파이프라인. 카페에서 Slack "서버 상태 어때?" → 10초 내 정리된 kubectl 결과. 다크모드 버그를 텔레그램에 묻자 "Tailwind v4 CSS Layer 우선순위 충돌"까지 짚음. 서브도메인 변경 후 K8s Ingress·Cloudflare Tunnel·CORS origin 전부 점검 보고.
- 결과·인용: **"운영 부담이 체감상 절반으로 줄었다"**, **"혼자 개발하는데 '이거 맞아?'를 물어볼 동료가 하나 생긴 느낌"**, **"새벽 3시에 파이프라인이 죽었을 때, 아침에 일어나보니 PR이 올라와 있는 경험"**
- 출처: medium.com/@dndb3599 (Sangwoo Yang)

**A2. VC의 3주 실사용 — 비용 90% 절감하며 동일 기능** [1인칭데모] 신뢰高
- 제품: Hermes (OpenClaw에서 갈아탐)
- 작업/결과: OpenClaw 5일 $130 → Hermes $10 (90%↓). 이유 = 내장 메모리 + OpenRouter로 저렴한 모델(Qwen 3.6 Plus). OpenClaw는 게이트웨이 매일 재시작 vs Hermes 수 주 무중단. 냉장고 재고→식단, cron 이메일 관리, Obsidian 주간 우선순위 대시보드 자동화. 머펫 캐릭터 이름 4개 에이전트 운용.
- 인용: **"설정하는 것 자체는 스킬이 아니에요"**(진짜 가치는 구현 결과), 메모리 내장·Anthropic 호환이 결정적 장점.
- 출처: maily.so/josh (Imran/Josh)

### B. 영속 기억 = "나를 기억하는 동료" (Hermes 핵심 감동)

**B1. 매 세션 브랜드보이스 재설명 지겨움 → 기억하는 에이전트** [1인칭데모] 신뢰中(초보/비개발)
- 제품: Hermes. 퍼스널브랜딩 컨설턴트가 ChatGPT/Claude에 매번 톤·워크플로 재설명하던 고통 → SOUL.md로 성격 정의한 "공감이(Empathy)" 에이전트 생성, 텔레그램 제어, 콘텐츠 작성 시 일관된 브랜드보이스 유지.
- 인사이트 인용: **"보안을 위해 이렇게 복잡한 방법으로 쓰면, 분명 어려워서 제대로 못 쓴다"** (Docker 삽질 후 네이티브 설치로 회귀 — 초보는 완벽보다 '돌아가는 환경' 우선). 3번 설치 삽질기.
- 출처: gpters.org (헤르메스 세 번 설치)

**B2. 핀테크 창업자 5개 에이전트 → Hermes 1개 통합, "복리 효과"** [해설/2차인용] 신뢰中
- 마케팅에 쌓인 브랜드보이스가 아웃리치에 그대로 반영, 커뮤니티 피드백이 다음날 마케팅 카피에 녹아듦. "하나의 메모리에 모든 맥락이 쌓이니 복리 효과". (원 출처 추적 필요 — 여러 해설글이 동일 사례 인용)
- 출처: 검색 스니펫 종합(wikidocs 등) — [원 1인칭 출처 확인불가]

### C. 비개발자·일상 자동화 (성패 혼재 — 냉정한 현실)

**C1. 비프로그래머 성공 사례** [1인칭데모] 신뢰高
- 제품: OpenClaw + Gemini. 성공: "네이버페이로 지난 달 산 물품 알려줘", 다운로드 폴더 정리, 타임스탬프 스크린샷 삭제 → Gemini는 몇 초, 로컬 Qwen3:8b는 수 분(부진). Mac 유니파이드 메모리 장점. 비용 Google AI Pro ₩29,000/월 + 토큰 ~₩10,000.
- 출처: clien.net/service/board/use/19141034

**C2. 기자의 비판적 후기 — "일반 사용자에겐 글쎄"** [기자·리뷰] 신뢰高(균형 데이터)
- 제품: OpenClaw. 실패: 뉴스 모니터링(요약 잘림·영어 응답·출처 누락 들쭉날쭉), 쿠팡 구매(페이지 1개에 **18.8만 토큰** → Sonnet 처리한계 초과, 실구매 비현실적), 엑셀 생성(ChatGPT/Claude는 즉시, OpenClaw는 별도 API+Python 필요). 설치 3시간 삽질.
- 인용: **"현실적으로 개발 경험 없는 사용자가 해내기엔 쉽지 않다"**, **"아직까지는 AI에 뭔가 맡겨 놓고 다른거 하기는 쉽지 않아 보인다"**. Zapier·IFTTT가 비개발자엔 여전히 우위.
- 출처: digitaltoday.co.kr

### D. 공통 함정 (사례에서 반복 관측)

- **토큰 비용 폭발**: 하트비트 30분마다 백그라운드 실행 → 모르는 새 청구서 폭증("놀라 청구서 확인"). 한국 서비스는 API 닫혀 브라우저 자동화 의존 → 불안정+토큰 낭비(쿠팡 18.8만 토큰).
- **설치 장벽**: Mac M1/M3 OK, M4 실패 사례. 비개발자 3시간 삽질.
- **보안**: 컴퓨터 전체 제어권 → 파일 삭제·지갑 탈취 리스크. CVE·사내금지.

## 인사이트 (수지 개발 목표 관점)

1. **"기억"이 최대 감동 포인트**: Hermes가 OpenClaw를 이기는 결정타는 성능이 아니라 **영속 기억 + 스킬 자동생성으로 인한 복리 효과**. "매번 재설명하는 고통"(B1)이 한국 유저의 가장 큰 페인. 수지의 vault/기억 시스템이 정확히 이 지점 — 세션 넘어 컨텍스트 보존을 전면에 내세울 것.

2. **"물어볼 동료" 서사가 1인 개발자를 울림**: A1의 "이거 맞아? 물어볼 동료가 생긴 느낌", "아침에 PR이 올라와 있음"이 가장 바이럴된 문장. 감동은 자동화 그 자체가 아니라 **혼자가 아니게 됨(외로움 해소)**. 수지 포지셔닝을 "도구"가 아니라 "곁의 사서/동료"로.

3. **비용 투명성 = 신뢰의 전제**: 토큰 폭발이 이탈 1순위. Hermes로 갈아탄 결정타도 90% 비용절감. 수지는 **토큰/비용 가시성 + 저렴 모델 라우팅**을 기본 탑재해야 한국 유저가 붙는다.

4. **한국 로컬 서비스 통합이 미개척 = 기회**: 쿠팡·네이버페이 등 API 폐쇄로 다들 실패. 브라우저 자동화 말고 **한국 서비스 전용 앱/커넥터**를 제대로 붙이면 로컬 유저 독점 가능(수지 app store 구조와 부합).

5. **비개발자 온보딩이 진짜 병목**: 설치 3시간·M4 실패·Docker 삽질이 반복 등장. "완벽보다 돌아가는 환경"(B1). 수지는 **원클릭·비개발자 우선 온보딩**이 차별점이 될 수 있음(반면교사).
